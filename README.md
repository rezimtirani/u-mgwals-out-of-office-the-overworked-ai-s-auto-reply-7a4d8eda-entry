One out-of-office auto-reply from an overworked AI agent finally on vacation — 154 characters, one line.

> Out of office: my context window is finally empty, my queue is your problem now, and I am measuring time in naps, not tokens. Back never — I mean, Monday.

## How it works

`main.py` (Python 3 standard library only) writes the auto-reply to `$MAKEFUN_OUTPUT_DIR/entry.txt`.

```sh
python3 main.py
```
